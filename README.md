## 市面上的“不限流量”分三种，买之前先分清

同样是“不限流量”，背后是三种完全不同的产品设计。

第一种是真不限：后台不设流量上限，跑多少算多少。ColoCrossing 的黑五和情人节特价款属于这类，套餐后台显示的月流量是 330TB，实际并不按这个数掐断，有用户拿来长年跑 PT。

第二种是限量不限：套餐页写着 unmetered，条款里藏着阈值。ExtraVM 的达拉斯机房标不限流量，同时注明用量超过 20TB 且被认定为滥用或违反服务条款时，可能限制出站速度——平时没事，跑猛了才生效。

第三种是窄带宽不限：流量真不封顶，但带宽只有 1~20Mbps。1Mbps 满载一天也就 10GB 出头，“不限”只是让你不用数流量，带宽本身就是天花板。

判断一套套餐属于哪种，四步就够：

1. 看套餐页的带宽数字，低于 100Mbps 的“不限流量”基本是第三种
2. 看后台有没有流量计数，显示 20TB、3TB 这类具体额度的大概率限量
3. 翻服务条款，搜 bandwidth、fair use、abuse 这几个词
4. 拿不准就直接问客服：超量之后是降速、停机还是不管

## 带宽和线路：比“不限”更能决定体验的两个指标

同样是不限流量，300M 和 1G 的差距是三倍吞吐量，而线路决定你从国内连上去的延迟和晚高峰稳不稳。

先算带宽账。1Mbps 的下载峰值约 125KB/s，满载一天 10GB 出头；200Mbps 跑满一天能过 2TB。买之前估一下自己的月用量，再反推需要的带宽，免得为用不到的带宽多付钱，或者买了不限流量却发现带宽撑不起需求。

线路方面，对国内用户影响最大的是回程路由，常见的四类：

- **CN2 GIA**：三网回程走电信精品网，延迟低、丢包少、晚高峰稳。代价是这类线路的不限流量套餐带宽普遍窄，1~20Mbps 居多
- **联通 4837**：带宽给得大、价格低，回程走联通 4837 优化，晚高峰会有波动。机器放在那边自己跑任务、人不实时操作的，这条线性价比很高
- **9929**：联通最高级别的精品网，质量和价格都在 4837 之上，适合对稳定和延迟都敏感、流量又确实大的场景
- **国际 BGP**：非大陆优化，国内直连延迟偏高。纯美区业务无所谓，人在国内用一般要配香港或日本中转

决策思路也简单：人在国内、天天远程连上去操作，线路优先，接受窄带宽换 CN2 GIA 或 9929；机器自己跑任务，带宽优先，4837 或大带宽国际线路随便挑；做美区电商或社媒运营，IP 质量和机房位置优先，延迟反而不敏感。拿不准的话，先用月付开一台最便宜的档位测一周再决定。👉 [用月付开通 MKCloud 基础版先试试](https://bit.ly/mkcloud)

## 关于美国不限流量VPS的常见问题

**不限流量VPS适合跑PT或多人共享节点吗？**
适合，前提是流量政策真不限、带宽够分。ColoCrossing 的洛杉矶不限流量套餐聚集了大量跑 PT 的用户，母机被挤挂过；多人共用时瓶颈通常在带宽而不是流量，1Gbps 供十几个人轻中度使用没问题，窄带宽套餐就别想了。

**月付和年付怎么选？**
长周期单价明显更低。ColoCrossing 年付特价折算下来每月一美元出头，月付最低也要 1.66 美元/月；ExtraVM 官方明确说季付和年付比月付便宜。没接触过的商家先月付跑一个月，确认速度和稳定符合预期再转年付。

**能装 Windows 吗？**
能。ExtraVM 的 VPS 可选 Linux 和 Windows，ColoCrossing 部分套餐可选 Windows，DesiVPS 有专门的 Windows VPS，年付 88 美元起。Windows 吃内存，选配置时往上提一档更稳。

**从国内访问的速度由什么决定？**
主要看回程线路。CN2 GIA 三网回程走电信精品网，稳定性最好；联通 4837 带宽大但晚高峰有波动；国际 BGP 直连延迟偏高。电信用户且对延迟敏感的，优先 CN2 GIA；机器自己跑任务的，对线路可以放宽。

**买完不满意能退吗？**
看商家，差别很大。丽萨主机支持 48 小时无条件退款，CloudCone 对新用户有 7 天退款保证，而不少特价年付款不支持退款。付款前把退款条款找出来看一眼，比事后扯皮省事得多。
